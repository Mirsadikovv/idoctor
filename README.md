# iDoctor Bot - Telegram Bot для управления ремонтной мастерской

Этот Telegram бот предоставляет интерфейс для управления ремонтной мастерской, позволяя отслеживать заказы, управлять мастерами и просматривать статистику.

## Возможности

### Для администраторов:
- ✅ Просмотр всех заказов
- ✅ Создание новых заказов
- ✅ Управление мастерами (просмотр профилей, активация/деактивация)
- ✅ Назначение мастеров на заказы
- ✅ Просмотр статистики и аналитики
- ✅ Поиск заказов

### Для мастеров:
- ✅ Просмотр своих заказов
- ✅ Изменение статуса заказов
- ✅ Поиск заказов

### Общие функции:
- ✅ Мультиязычность (русский, узбекский, английский)
- ✅ Уведомления о статусе заказов
- ✅ Интуитивный интерфейс с inline-кнопками

## Установка и запуск

### Требования

- Go 1.19+
- PostgreSQL 12+
- Telegram Bot Token (получить от @BotFather)

### Настройка базы данных

1. Создайте базу данных PostgreSQL:
```sql
CREATE DATABASE idoctor_bot;
CREATE USER idoctor_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE idoctor_bot TO idoctor_user;
```

2. Загрузите тестовые данные:
```bash
psql -U idoctor_user -d idoctor_bot -f test_data.sql
```

### Настройка окружения

1. Скопируйте файл конфигурации:
```bash
cp .env.example .env
```

2. Отредактируйте `.env` файл:
```env
# Telegram Bot Configuration
BOT_TOKEN=your_telegram_bot_token_here
BOT_DEBUG=false

# Database Configuration  
DB_HOST=localhost
DB_PORT=5432
DB_NAME=idoctor_bot
DB_USER=idoctor_user
DB_PASSWORD=your_password
DB_SSLMODE=disable

# API Configuration (опционально)
API_ENABLED=false
API_BASE_URL=http://localhost:8080
API_KEY=your_api_key_here

# Admin Configuration
ADMIN_TELEGRAM_IDS=123456789,987654321
```

### Компиляция и запуск

1. Установите зависимости:
```bash
go mod download
```

2. Скомпилируйте проект:
```bash
go build -o idoctor-bot .
```

3. Запустите бота:
```bash
./idoctor-bot
```

## Команды бота

- `/start` - Регистрация и главное меню
- `/menu` - Показать главное меню
- `/orders` - Мои заказы (для мастеров)
- `/help` - Справка
- `/lang` - Смена языка

## Основные функции для мастеров

### 1. Просмотр профиля мастера
- Показывает полную информацию о мастере
- Статистика заказов (всего, завершено, в работе)
- Общая выручка и рейтинг
- Возможность активации/деактивации (только для админов)

### 2. Управление заказами мастера
- Просмотр всех заказов мастера
- Отображение статуса, клиента, стоимости
- Ограниченный список (первые 5 заказов)

### 3. Переключение статуса мастера
- Админы могут активировать/деактивировать мастеров
- Мгновенное обновление интерфейса
- Логирование всех изменений

## API интеграция

Бот поддерживает интеграцию с основной системой через REST API:

- `GET /api/v1/devices` - получение всех заказов
- `GET /api/v1/devices?master_id=X` - заказы мастера
- `PUT /api/v1/devices/{id}/status` - изменение статуса
- `GET /api/v1/users?telegram_id=X` - информация о пользователе

## Статусы заказов

| Статус | Описание | Иконка |
|--------|----------|--------|
| received | Принят | 🆕 |
| inProgress | В работе | 🔧 |
| waitingParts | Ожидание запчастей | ⏳ |
| ready | Готов | ✅ |
| completed | Выдан | 📦 |
| cancelled | Отменен | ❌ |

## Разработка

### Добавление новых функций

1. Создайте новый handler в `app/handler/privates/`
2. Добавьте переводы в `app/i18n/texts.go`
3. Обновите клавиатуры в `app/handler/privates/keyboards.go`
4. Добавьте бизнес-логику в `app/services/`
