# iDoctor Bot - Telegram-бот ремонтной мастерской

Telegram-бот для автоматизации работы ремонтной мастерской, созданный на основе архитектуры `dmi_bot`.

## 🔧 Возможности

### Для мастеров:
- 📋 Просмотр назначенных заказов
- 🔄 Изменение статуса заказов
- 💰 Установка цены ремонта и запчастей
- ⏰ Отслеживание сроков выполнения
- 📊 Просмотр статистики работы

### Для администраторов:
- 📊 Просмотр всех заказов в системе
- 👥 Управление мастерами
- 📈 Аналитика и отчеты
- ➕ Создание новых заказов (планируется)
- 🔧 Назначение мастеров на заказы (планируется)

## 🏗️ Архитектура

Бот интегрируется с существующей системой `version_1` и использует те же модели данных:
- `User` - пользователи (мастера и админы)
- `Customer` - клиенты
- `Device` - устройства в ремонте
- `Part` - запчасти

## 📦 Установка

### Требования
- Go 1.21+
- PostgreSQL
- Telegram Bot Token

### Шаги установки

1. **Клонирование и переход в папку:**
```bash
cd idoctor_bot
```

2. **Установка зависимостей:**
```bash
make deps
```

3. **Настройка окружения:**
```bash
cp .env.example .env
# Отредактируйте .env файл с вашими настройками
```

4. **Настройка .env файла:**
```env
# Database
DB_HOST=localhost
DB_PORT=5432
DB_USER=postgres
DB_PASSWORD=your_password
DB_NAME=repair_bot
DB_SSLMODE=disable

# Telegram Bot
TELEGRAM_BOT_TOKEN=your_bot_token_here
TELEGRAM_DEBUG=false
TELEGRAM_ADMIN_IDS=123456789,987654321
```

5. **Сборка и запуск:**
```bash
make run
```


### Команды бота
- `/start` - Регистрация в системе
- `/menu` - Главное меню
- `/orders` - Просмотр заказов
- `/help` - Справка

## 🗄️ База данных

Бот использует те же таблицы, что и система `version_1`:
- `users` - пользователи системы
- `customers` - клиенты
- `devices` - устройства в ремонте  
- `parts` - запчасти

Автомиграция выполняется при запуске бота.

### Добавление нового функционала
1. Создайте новый обработчик в `app/handler/privates/`
2. Добавьте команду в `handlers.go`
3. Обновите клавиатуры в `keyboards.go`
4. Протестируйте с помощью `make test`

## 📝 Логи

Бот ведет логи всех операций. Уровень логирования настраивается через переменную `LOG_LEVEL` в `.env`.

## 🐛 Устранение неполадок

### Проблемы с базой данных
- Убедитесь, что PostgreSQL запущен
- Проверьте настройки подключения в `.env`
- Проверьте права доступа пользователя БД

### Проблемы с Telegram API
- Убедитесь, что токен бота корректный
- Проверьте, что бот не заблокирован
- Убедитесь, что у бота есть права на отправку сообщений
